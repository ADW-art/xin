## 一、一句话定位

**一个面向编程/计算机学习者的个性化学习系统：以"多智能体协作"为骨架，融合三大自研算法（贝叶斯知识追踪、知识图谱学习路径、企业级混合检索），基于真实教材知识库与讯飞星火大模型，提供"画像采集→资源生成→自适应出题→学习评估→路径规划"的全流程闭环。**

---

## 二、背景与痛点

传统在线学习的三大问题：
1. **千人一面**：所有人看同样的资料、做同样的题，不区分基础与目标。
2. **黑箱评估**：只给分数，不知道"哪个知识点没掌握、为什么错、下一步学什么"。
3. **检索不可靠**：直接问大模型容易"幻觉"，缺乏可溯源的教材依据。

**我们的切入点**：用"多智能体 + 知识追踪 + 知识图谱 + 可溯源检索"把"个性化"做实，而不是停留在概念。

## 五、核心创新 ①：BKT 贝叶斯知识追踪（自研算法）

**做什么**：用贝叶斯方法实时估计学生对每个知识点的"掌握概率"，并据此驱动自适应出题。

**算法**：经典 Corbett & Anderson (1995) 四参数模型
- P(L₀) 初始掌握概率、P(T) 学习迁移率、P(G) 猜对率、P(S) 失误率
- 每次答题后用贝叶斯公式更新 P(已掌握)，连续答对→升难度，答错→降难度
- **工程增强**：① EM 参数自动拟合（每 5 次答题自动校准四参数）；② 概念名称治理（把用户输入的概念规范化映射到知识图谱标准词，避免脏数据污染追踪）

**亮点**：不是"答对率统计"，而是有数学模型的概率推断——能区分"真掌握"与"蒙对"，并预测遗忘。

**真实性**：单元测试 102/102 通过；已修复一处概念治理的真实 bug（过度模糊匹配导致概念错配）。

---

## 六、核心创新 ②：知识图谱 + 学习路径规划（自研算法）

**做什么**：把知识点连成有向图，按"前置依赖"为学生排出最优学习顺序。

**算法链**：
1. TF-IDF 知识点提取 + 共现分析 → 构建知识点有向图（DAG）
2. **拓扑排序**保证"先学前置、再学进阶"
3. 结合每周可投入时间估算学习周期
4. **艾宾浩斯遗忘曲线**插入复习节点（间隔递增复习 / Spaced Repetition）
5. 知识图谱治理：注入精选的计算机学科知识点与前置依赖边，过滤噪声

**亮点**：学习路径不是固定模板，而是"拓扑排序 + 掌握度 + 时间约束"动态生成的 DAG，前端用力导图可视化。

---

## 七、核心创新 ③：企业级混合检索 RAG（自研架构）

**做什么**：让大模型基于真实教材作答，可溯源、抗幻觉。

**四路融合架构**：
```
query ─BGE向量─┬─①稠密召回  FAISS(按学科分子索引) ─降级→ ChromaDB
               └─②稀疏召回  BM25(jieba 中文分词)
                    └─③RRF 排名融合 ──④CrossEncoder 精排──▶ Top-K
```
- **稠密召回**：bge-large-zh-v1.5 把文本编码为 1024 维归一化向量，FAISS 内积检索（= 余弦相似度）
- **稀疏召回**：jieba 分词 + BM25Okapi 关键词匹配
- **RRF 融合**：Reciprocal Rank Fusion 合并两路排名
- **精排**：bge-reranker-v2-m3 交叉编码器对候选做语义重排
- **主备双引擎**：FAISS 主（按学科分片路由：os/database/datastructure/clang/java/default），ChromaDB 备（不可用时自动降级），优雅降级保证可用性

**真实性（实测）**：知识库 39,005 块教材正文真向量；语义检索实测——"TCP三次握手"命中《计算机网络》原文(score 0.808)、"快速排序复杂度"命中《算法导论》、"二叉树遍历"命中数据结构教材。质量审计：92% 片段有效，乱码经过滤治理。

---

## 八、多智能体协作（LangGraph）

- **调度中枢 Supervisor**：用大模型对用户意图分类，路由到对应 Agent。
- **6 个专职 Agent**：
  - `profile`：6 维画像对话式采集 + MySQL 持久化
  - `resource`：5 类资源生成（文档/思维导图/题集/讲解脚本/代码案例），注入 RAG 检索结果
  - `question`：BKT 自适应出题 + 题库检索
  - `path`：知识图谱拓扑排序 + 艾宾浩斯复习
  - `evaluation`：6 维评估报告（基于真实答题与 BKT 数据）
  - `chat`：通用对话兜底
- **共享状态 AgentState**：messages / user_profile / context / agent_outputs / user_id 在图中流转。
- **SSE 流式**：逐 token 推送，前端打字机效果；中途推送 agent_switch、resource 卡片等事件。
- **会话记忆**：MemorySaver + SQLite checkpoint，按 thread_id 持久化多轮上下文。
