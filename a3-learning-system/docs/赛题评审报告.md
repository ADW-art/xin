## 二、关键逻辑闭环断裂 (扣分最多的部分)

### 断裂 1: BKT → Profile → Path 三者数据流未打通

```
Profile Agent 写入 knowledge_base (dict)
    ↓
_compute_dimension_scores 强转 string (丢失结构)
    ↓
BKT 记录答题 topic，未调用 normalize_concept_name
    ↓
Path Agent 读取 BKT mastered 列表，原始名不匹配 KG 节点
    ↓
所有无法匹配的概念坍缩到同一个 "未分类" BKT 节点
```

### 断裂 2: 复习调度器数学不成立且无主动推送

- `memory_strength` 初始值 = 0.5 → 1 天后 retention = e^(-1/0.5) = 13.5%
- 标准艾宾浩斯曲线 1 天保留率约 70%，对应 S ≈ 5-7
- 即使复习到最大值 S=2.0，1 天后也只剩 60%
- `get_due_reviews()` 无主动推送机制，仅在 path_agent 执行时被动展示

### 断裂 3: 答题→评分→BKT→下一题不自洽

- 答题缓存 TTL=1h，超时后用户答案丢失，永不会触发 grade 模式
- `extract_answer_map` regex 仅接受特定格式，自然语言回答无法解析
- `parse_grading_result` regex 脆弱，LLM 格式偏差即用猜解算法

### 断裂 4: RAG 冷启动静默失败

- BGE-M3 首次加载数分钟，`is_rag_ready()==False` 时静默降级
- `hybrid_search` 公共 API 无 ready 检查，首次调用必超时

### 断裂 5: Mermaid 饼图无条件注入每条回复

- chat.py:964-989 在所有 Agent 回复后追加 BKT 饼图
- evaluation_agent 又追加一次 → 评估报告出现重复图表
