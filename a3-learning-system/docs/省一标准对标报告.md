## 二、逐维度详细评审

### 2.1 技术创新性 — 92 分（省一要求 ≥80）✅

**三大自研算法是真正的亮点**：

| 模块 | 实现 | 评审 |
|------|------|------|
| **BKT 知识追踪** (`bkt_service.py`) | 标准四参数模型 + 遗忘参数 P(F) 五参数扩展，per-skill 个性化参数，MySQL 持久化 | **省一核心得分点**。代码 350+ 行，有完整的贝叶斯后验更新公式实现、学术引用（Corbett & Anderson 1995）、环境变量可配置参数、难度自适应调节。比"连对2题升难度"的玩具方案高一个量级。 |
| **知识图谱拓扑排序** (`knowledge_graph.py`) | TF-IDF 知识点提取 → 共现矩阵 → DAG 构建 → 拓扑排序 → 学习路径生成 | 自研非调包。从文本中自动提取知识点的共现关系构建 DAG，计算每个节点的入度/出度/层深/关键路径。这比简单的"推荐列表"或调包方案有本质区别。 |
| **混合检索 RAG** (`rag_service.py`) | FAISS 稠密 + BM25 稀疏 + RRF 融合 + BGE-Reranker-v2-m3 CrossEncoder 精排，四阶段流水线 | 企业级架构。`rag_trace()` 返回每阶段中间结果供前端可视化，`retrieve_context()` 带 15s 超时控制，BGE 模型加载失败自动降级到纯 LLM。这是省赛中极少见的完整 RAG 实现。 |

**附加创新点**：
- 艾宾浩斯遗忘曲线复习调度 (`review_scheduler.py`)：间隔递增复习（1/3/7/14/30 天）
- FAISS 多子索引管理 (`faiss_client.py`)：按学科分索引 + 路由 + 懒加载
- 内容安全守卫 (`content_guard.py`)：安全过滤 + 防幻觉检测 + 流式兼容
- 静默画像采集 (`_silent_profile_collect`)：从自然对话中提取背景信息
- 学习闭环反馈 (`_extract_and_boost` + `_boost_knowledge_score`)：学习行为自动更新知识掌握度
