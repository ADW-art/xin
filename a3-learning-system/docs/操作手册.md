## 一、GitHub 操作

### 第一次配 SSH（推荐，免密码）

```bash
# 1. 生成密钥（一路回车）
ssh-keygen -t ed25519 -C "你的邮箱"

# 2. 复制公钥
cat ~/.ssh/id_ed25519.pub

# 3. 去 GitHub → Settings → SSH Keys → New SSH Key → 粘贴
# 4. 切换远程地址为 SSH
git remote set-url origin git@github.com:ADW-art/xin.git
```

### 每次提交三板斧

```bash
git status          # ① 看改了啥
git add .           # ② 全加暂存区（.env/密钥 已被 gitignore 拦住）
git status          # ③ 再确认一眼绿名单
git commit -m "..." # ④ 提交
git push origin main # ⑤ 推
```

### 提交消息怎么写

```
"Add: Spark API 封装"        → 新增功能
"Fix: SSH 连接超时"          → 修bug
"Update: Docker Compose 端口" → 改了已有东西
"Docs: 添加操作手册"         → 纯文档
```

### 失败处理

```bash
# 被拒绝（远程有新代码）
git pull origin main --rebase
git push origin main

# 推错文件了
git reset HEAD 文件名        # 从暂存区撤回
git checkout -- 文件名        # 放弃本地修改（慎用）

# 网络错误
# → 检查代理开了没
git config --global http.proxy
```

## 二、Docker 操作

### 基础设施开关

```bash
# 启动（在项目根目录）
docker-compose up -d

# 看是否全绿
docker ps

# 停止（保留数据）
docker-compose down

# 停止 + 清数据
docker-compose down -v
```

### 四个服务端口号

| 服务 | 端口 | 用途 |
|------|------|------|
| MySQL | 3307 | 数据库 |
| Redis | 6379 | 缓存 |
| MinIO | 9000（API）/ 9001（控制台） | 文件存储 |
| ChromaDB | 8000 | 向量检索 |

### 连 MySQL

```bash
# 进容器
docker exec -it a3-mysql mysql -u a3_user -p

# 输密码：a3_pass
```

### 容器故障

```bash
# 某个挂了 → 重启
docker restart a3-mysql

# 完全不清楚状态 → 全清重来
docker-compose down -v
docker-compose up -d
```

## 三、开发运行

### 后端启动

```bash
# 方式1：虚拟环境（推荐）
docker compose up -d mysql
cd a3-learning-system/backend
.\venv\Scripts\python.exe -m uvicorn app.main:app --reload --port 8001

# 方式2：全局 Python（如果全局也装了依赖）
cd a3-learning-system/backend
python -m uvicorn app.main:app --reload --port 8001
```

- API 文档：`http://localhost:8001/docs`
- 健康检查：`http://localhost:8001/api/health`

> **注意**：如果 MySQL 没启动，服务会打印警告但**正常启动**（聊天功能不受影响）。
> 端口用 8001 而非 8000，避免和 ChromaDB（占 8000 端口）冲突。

### 前端启动

```bash
cd a3-learning-system/frontend
npm install   # 首次或依赖变了
npm run dev
```

- 页面：`http://localhost:5173`

### 测试星火 API

```bash
cd a3-learning-system
python test_spark.py
```

成功 → 输出 `SUCCESS! Reply: 你好...`

## 四、Python 环境

```bash
# 创建虚拟环境（首次，在 backend 目录下）
cd a3-learning-system/backend
python -m venv venv

# 激活（Windows PowerShell）
.\venv\Scripts\Activate.ps1

# 激活（Windows Git Bash / CMD）
source venv/Scripts/activate
# 或
.\venv\Scripts\activate.bat

# 安装依赖（首次或 requirements.txt 变了）
pip install -r requirements.txt

# 退出虚拟环境
deactivate
```

### 已知的依赖问题

```bash
# 如果 pip install 报依赖冲突：
# → langgraph 0.2.0 和 langchain 0.3.0 打架
# → 把 requirements.txt 里 langgraph==0.2.0 改成 langgraph>=0.2.20,<0.3
```

## 五、常用检查命令汇总

```bash
# Git 相关
git status                    # 文件状态
git log --oneline -5          # 最近 5 次提交
git remote -v                 # 远程地址
git ls-remote origin main     # GitHub 上最新 commit

# Docker 相关
docker ps                     # 运行中的容器
docker-compose ps             # Compose 管理的容器
docker logs a3-mysql          # 看某个容器的日志

# API 测试
curl http://localhost:8001/api/health    # 后端活着吗
curl http://localhost:8001/docs          # API 文档页

# 环境检查
python --version              # Python 版本
node --version                # Node 版本
pip list | grep fastapi       # 某个包装了没
```
