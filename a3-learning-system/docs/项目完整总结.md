## 一、项目概况

| 项目 | 详情 |
|------|------|
| **赛题** | 基于大模型的个性化资源生成与学习多智能体系统开发 |
| **比赛** | 中国软件杯 |
| **出题方** | 科大讯飞 |
| **截止日期** | 2026-06-30 |
| **当前阶段** | MVP 核心闭环开发中 |

### 项目简介

一个 **AI 驱动的个性化学习系统**。用户与多智能体对话交互，系统自动采集学习画像，根据画像生成个性化学习资源（文档/思维导图/练习题/代码案例），规划最优学习路径，并进行多维度学习评估。

**一句话**: 每个学生都有一个 AI 私教团队，懂你的基础、风格和目标，为你量身定制学习内容。

## 三、多智能体架构（核心创新点）

### 6 个 Agent 分工

```
用户输入
   │
   ▼
┌──────────────┐
│  Supervisor  │  ← 意图分类 + 路由决策
│  (调度中枢)   │     "想学Python" → ResourceAgent
└──────┬───────┘     "来点题目" → QuestionAgent
       │
       ├── ProfileAgent      → 对话采集6维学习画像
       ├── ResourceAgent     → 生成文档/导图/题库/代码/视频脚本
       ├── QuestionAgent     → 自适应出题，难度动态调整
       ├── PathAgent         → DAG 学习路径规划（拓扑排序 + 遗忘曲线）
       └── EvaluationAgent   → 6维雷达评估 + 改进建议
       │
       ▼
   回到 Supervisor（可继续路由或结束）
```

### 共享状态 (AgentState)

所有 Agent 共享一个状态对象，通过 LangGraph 自动传递：

- `messages` — 完整对话历史（自动追加）
- `user_profile` — 6 维学习画像（知识点掌握度/认知风格/学习目标/时间投入/易错模式/偏好资源类型）
- `agent_outputs` — 各 Agent 的输出缓存
- `stream_buffer` — SSE 流式输出缓冲区
- `context` — 当前上下文（主题、任务等）

### LangGraph 状态图

采用 Supervisor 模式（官方推荐的多 Agent 协作模式）：
- Supervisor 节点作为入口，理解意图后路由到对应 Agent
- 每个 Agent 执行完毕后回到 Supervisor，判断是否继续调度
- 支持 checkpoint（Redis 持久化），中断后可从断点恢复

## 四、核心功能模块

### 1. 智能对话（ChatView）
- SSE 流式对话，逐字打字效果
- 多 Agent 自动切换（用户无感知）
- 消息支持 Markdown + 代码高亮 + 思维导图 + 资源卡片

### 2. 学习画像（6 维模型）
| 维度 | 采集方式 | 示例 |
|------|---------|------|
| 知识基础 | 对话问答 | "Python 掌握度 60%" |
| 认知风格 | 对话了解 | visual/auditory/kinesthetic/reading |
| 学习目标 | 直接询问 | 考试/技能/职业/兴趣 |
| 时间投入 | 直接询问 | 每周 8 小时 |
| 易错模式 | 答题数据分析 | list/tuple 混淆 |
| 资源偏好 | 对话了解 | 视频/文档/代码/互动 |

### 3. 个性化资源生成
- **知识文档**: 结构化 Markdown（匹配认知风格）
- **思维导图**: Markdown 标题层级 → markmap 渲染
- **练习题**: 3-5 题，含答案+解析，难度自适应
- **视频脚本**: 5 分钟讲解，分镜头描述
- **代码案例**: 可执行 Python 代码，含注释

### 4. 自适应出题
- 初始诊断测试：广覆盖、适中难度
- 学习后测试：聚焦刚学知识点
- 难度动态调整：连对 2 题升难度，答错降难度
- 题型混合：选择 60% + 填空 20% + 代码 20%

### 5. 学习路径规划 (DAG)
- 基于知识图谱的拓扑排序
- 前置知识必须先学
- 考虑时间投入计算周数
- 穿插遗忘曲线复习节点
- 评估后动态调整后续路径

### 6. 多维度评估报告
- 6 维雷达图（知识掌握/学习速度/薄弱环节/进步趋势/投入度/推荐策略）
- 文字建议 + 可视化图表

## 五、数据流（以"生成学习资源"为例）

```
1. 用户在 ChatView 输入: "我想学Python基础"
2. 前端 POST /api/chat/send → SSE 连接建立
3. FastAPI → LangGraph 入口 (Supervisor)
4. Supervisor 调用星火 API 做意图分类 → intent="resource", topic="Python基础"
5. 路由到 ResourceAgent
6. ResourceAgent:
   a. 从 MySQL 读取用户画像
   b. 从 ChromaDB 检索相关教材片段 (RAG)
   c. 拼装 Prompt → 调用星火 API 生成个性化文档
   d. 生成的文档存 MinIO
   e. 元数据存 MySQL + ChromaDB
   f. 流式输出给前端 (SSE)
7. 前端 StreamingText 逐字显示
8. 生成完成后自动插入 ResourceCard 组件
```

## 六、数据库设计

### MySQL（6 张核心表）
- `users` — 用户账号
- `learning_profiles` — 6 维学习画像 (JSON 字段)
- `conversations` — 对话历史 (含 agent_type)
- `resources` — 学习资源 (含文件URL、知识点、难度)
- `answer_records` — 答题记录 (含正确性、用时)
- `learning_paths` — 学习路径 DAG (JSON 字段)
- `assessment_reports` — 评估报告 (JSON 字段)

### ChromaDB（4 个集合）
- `knowledge_base` — 教材/课件文本切片
- `resource_embeddings` — 资源摘要向量
- `question_bank` — 题库向量
- `error_patterns` — 错误模式向量

### Redis（5 种键）
- `session:{id}` — 会话管理 (TTL 24h)
- `blacklist:{jti}` — JWT 黑名单
- `chat_context:{user_id}` — 对话上下文缓存 (TTL 1h)
- `checkpoint:{thread_id}` — LangGraph 状态快照 (TTL 24h)
- `resource_queue` — 资源生成异步队列 (FIFO)

## 十、创新亮点（答辩得分点）

1. **多智能体协作架构 (LangGraph)**: 6 个专业 Agent 分工协作，而非单一大模型对话。状态图可视化可直接用于答辩展示。

2. **6 维学习画像模型**: 不仅追踪知识掌握度，还建模认知风格、易错模式、资源偏好等，实现真正的"因材施教"。

3. **全流程闭环**: 画像采集 → 资源生成 → 练习测试 → 路径规划 → 评估反馈，覆盖学习全生命周期。

4. **RAG + 防幻觉**: 基于教材/课件的向量检索增强生成，减少大模型幻觉，确保内容准确性。

5. **SSE 流式体验**: 逐字打字效果 + Agent 切换通知 + 资源自动内嵌，用户体验流畅。

6. **DAG 可视化学习路径**: Vue Flow 渲染知识图谱，学生一目了然"现在在哪、下一步学什么"。

7. **自适应难度**: 出题 Agent 根据连续正确/错误自动升降难度，保持最佳挑战水平。

8. **遗忘曲线复习**: 路径规划 Agent 在遗忘临界点自动插入复习节点。
