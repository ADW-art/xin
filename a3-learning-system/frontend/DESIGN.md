## 三、布局模式

```
┌──────────────────────────────────────────┐
│ 侧边栏 (220px, 深色)   │ 顶栏 (50px, 白色) │
│                        ├───────────────────┤
│                        │                   │
│                        │  内容区 (padding   │
│                        │  24px, 浅灰背景)   │
│                        │                   │
└──────────────────────────────────────────┘
```

### 关键原则
1. 内容区最大宽度 880-960px，居中显示
2. 页面之间的间距和字号完全统一
3. 卡片用 1px solid 边框 + 白色背景，不用大阴影
4. 侧边栏选中项：品牌色半透明背景 + 白色文字
5. 中文系统默认用思源黑体渲染

## 四、组件规范

### 页面标题区
- 24px 加粗标题 + 4px 下方 14px 灰色说明
- 标题与内容间距 28-32px

### 卡片
- 白色背景 + 1px #ebeef5 边框 + 8px 圆角
- 内部 padding 20px
- hover 时轻微上浮（translateY(-2px)）+ 阴影增强

### 空状态
- 居中，上间距 60-80px
- 72px 圆形灰色容器 + 36px 图标
- 16px 加粗标题 + 14px 灰色说明 + 下方按钮

### 输入框/表单
- 默认使用 Element Plus 自带样式
- 表单标签顶部对齐
- 按钮最小宽度 80px
